# Refrinova — Site Institucional

Site da **Refrinova**, empresa de engenharia térmica e refrigeração industrial.

🔗 **No ar:** https://refrinova.ind.br/

## Páginas

| Página | Conteúdo |
| --- | --- |
| `index.html` | Início: serviços e soluções |
| `sobre.html` | A empresa |
| `cases.html` | Projetos realizados e clientes |
| `contato.html` | Formulário, WhatsApp, telefone e e-mail |

## Destaques

- Site estático em HTML, CSS e JavaScript, sem etapa de build
- Layout responsivo com animações de entrada ao rolar
- Carrossel de projetos com Swiper
- Botão de WhatsApp para pedidos de orçamento

## Rodar localmente

Abra o `index.html` no navegador.
